Independent annotation packet

These five source views start without object or relation suggestions. For an independent review, save your own annotations before opening the agent annotations or comparison results. Group artwork from the original drawing; retain uncertainty and unobservable intent. A review status is self-reported, not verified identity.

Record your annotator type, identity, evidence and review status, then download each JSON. Preserve the original source hash and license. Two reviewers should label an overlapping subset separately before adjudication. Do not call an agent-created record human ground truth.
